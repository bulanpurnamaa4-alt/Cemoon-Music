💜 CEMOON MUSIC

A purple-themed Roblox Music Player project by Cemoon.

✨ Features

- Custom Music ID input
- Play and Stop buttons
- Purple-themed GUI
- Mobile-friendly interface
- Drag and move GUI (when supported by the script)

📦 Installation

Use the script in an environment that supports its execution requirements.

⚠️ Disclaimer

- Audio playback depends on Roblox audio permissions.
- This project does not guarantee that music will be audible to other players.
- Use responsibly and respect Roblox rules.
